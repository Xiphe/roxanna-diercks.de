# Publish content independently of the website

Readable, typed CMX replaces the Payload page builder so editorial changes can publish without deploying application code. Remix 3 owns presentation and interactive islands; a signed publication is accepted atomically by a Cloudflare Durable Object. Media is prepared with content and stored under immutable R2 keys. This follows Xiphe/hannesdiem's established publication boundary while retaining Roxanna's own visual design and Brevo destinations.
